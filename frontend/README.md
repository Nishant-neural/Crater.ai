# Crater.ai — Technical Visualization (Phase 4 frontend)

React + Vite app for Phase 4: an interactive schematic viewer, a component
explorer, and a procedure/repair-animation viewer, talking to the
`backend/visualization` API. See `../docs/Phase4.md` for scope and limits.

```bash
npm install
cp .env.example .env   # set VITE_API_BASE if the backend isn't localhost:8000
npm run dev
```
